# E-commerce Sales Data Quality and Analysis Project

## Project Overview
This project analyses a synthetic e-commerce sales dataset to demonstrate data cleaning, data validation, revenue analysis, and dashboard reporting using spreadsheet tools.

The project focuses on identifying data-quality issues and turning sales data into useful business insights.

## Tools Used
- Microsoft Excel
- Google Sheets
- Looker Studio (dashboard development)
- GitHub (project documentation and portfolio)

## Project Workflow
1. **Data cleaning:** Standardised SKU values and product categories.
2. **Data validation:** Checked for duplicate SKUs, missing prices, and unmatched product references.
3. **Data preparation:** Used lookup formulas to connect order records with product information.
4. **Revenue analysis:** Calculated gross sales, discounts, net revenue, estimated costs, and estimated gross profit.
5. **Dashboard reporting:** Created KPI summaries and charts to communicate the findings.

## Key Findings
- Total net revenue: **$24,770.03**
- Estimated gross profit: **$14,005.48**
- Matched order lines: **745**
- Unmatched order lines: **8**
- Matched order lines affected by missing product prices: **23**
- Highest-revenue sales channel: **Social**
- Top product by revenue: **Hoodie**
- Highest-revenue category: **Electronics**

## Data Quality Checks
The project includes checks for:
- Missing and duplicate product SKUs
- Unmatched SKUs in order records
- Missing product prices
- Missing product costs
- Consistency of revenue calculations

## Project Files
- `Ecommerce_Sales_Data_Quality_Project.xlsx` – the main workbook, including working sheets, analysis, and dashboard.
- `data/` – source data exports.
- `documentation/` – project and data-quality documentation.
- `screenshots/` – dashboard screenshots.

## Important Note
The dataset is synthetic and is used for demonstration and portfolio purposes. It does not represent actual customer transactions or confidential company data.
